# Krafen 🚀

[![Version](https://img.shields.io/badge/version-2.0.0-blue.svg)](https://github.com/krafenx/krafen)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**Krafen** is a modern, lightweight, and highly customizable open-source digital identity platform and modular dashboard engine. Built for developers, creators, and tech-savvy individuals, it serves as a deeply aesthetic, self-hosted alternative to proprietary link-aggregation tools.

With Krafen, you can transform a simple personal hub into a dynamic, real-time workstation that showcases your digital presence with absolute control over your data and design.

🔗 **Live Demo:** [krafen.online](https://krafen.online/)

---

## ✨ Features

* **Modular Architecture (v2.0.0):** A completely overhauled core layout designed for maximum performance, clean state management, and seamless scalability.
* **Experimental UI/UX Focus:** High-fidelity visual styling featuring advanced layout compositions, smooth interactive micro-animations, and custom theme switches.
* **Dynamic Identity Hub:** Engineered to support live third-party integrations (e.g., real-time GitHub activity feeds and dynamic status widgets) to reflect your live ecosystem.
* **Developer-First Boilerplate:** Highly optimized and modular codebase, making it incredibly easy for anyone to fork, tweak a configuration file, and deploy their own copy in minutes.

## 🛠️ Tech Stack

* **Framework:** [Next.js](https://nextjs.org/) (React)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Environment:** Optimized for modern edge runtimes and fast static/server deployments.
